# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Do not report security vulnerabilities in public issues.

Report it privately through [GitHub security advisories](https://github.com/FrancescoGrazioso/Meld/security/advisories/new) with a description of the issue, the affected version and steps to reproduce it. We will acknowledge your report and update you as we work on a fix.
